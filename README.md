# Job Search — Dr. Thejus Mahajan

Career transition from computational physics/ecology → clinical bioinformatics & data science.

## Directory Structure

| Directory | Question it answers |
|---|---|
| `applications/` | *What positions have I applied to, and what documents did I submit?* |
| `reference/` | *Where are my archival career documents (thesis, postdoc narrative, baseline CV)?* |
| `course_materials_further_training_bioinformatics_and_biostatistics/` | *What did I learn in the CQ Beratung + Bildung training program?* |

## Key Files

| File | Purpose |
|---|---|
| `PRINCIPLES.md` | Standing directives for how this project is managed |
| `APPLICATION_LOG.md` | Dated log of all applications — status, contacts, outcomes |
| `README.md` | This file |

## How to Add a New Application

1. Create a folder under `applications/` named after the institution and lab/team, e.g. `applications/mdc_berlin_ludwig_lab/`
2. Add a `requirements.md` with: contact info, lab description, position details, and a checklist
3. Copy `res.cls` and `thejus signature.jpg` from an existing application folder
4. Create `cv_<name>.tex` and `cover_letter_<name>.tex`, adapting from previous applications
5. Compile with `pdflatex`
6. Update `APPLICATION_LOG.md` with the new entry
